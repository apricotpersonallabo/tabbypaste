Three steps

From clipboard to form in seconds.

Tabby Paste works one row at a time and follows the visible form fields from the one you focus.

  1. Copy one row

    Select a single row in Excel, Google Sheets, or another table and copy it.

  2. Focus the first field

    Click the first text field, textarea, password field, or select you want to fill.

  3. Run Tabby Paste

    Use the keyboard shortcut or choose Tabby Paste from the page's context menu.

Built for real forms

Control where and how values are entered.

The extension stays small, but includes the controls needed for dynamic business forms.

Text fields, textareas, and selects

Values move through visible, editable fields in page order, replacing the current value as they go.

Enable only the sites you choose

Use wildcard URL patterns and the toolbar popup to limit or pause the extension.

Resilient select matching

Tabby Paste matches option values or labels and can wait briefly for dynamically rendered options.

Portable settings

Export enabled URLs, delay, and select-wait preferences as TOML, then import them later.

Private by design

Your clipboard data stays in your browser.

Tabby Paste has no account, analytics, ads, or developer-controlled server.

Local processing

Clipboard values are read only when you run the extension and are applied to the active page.

Browser-managed sync

Preferences use the browser's sync storage and are never sent to the developer.

Open source
