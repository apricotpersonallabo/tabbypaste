Choose your trigger

Run it from the keyboard or context menu.

Keyboard shortcut

The suggested shortcut is Ctrl+Shift+V. Open Settings to see the current shortcut or change it in the browser's shortcut page.

Context menu

Right-click the page after focusing the starting field, then choose Tabby Paste.

Field behavior

Supported fields and matching rules.

Tabby Paste scans the current page for visible, enabled, editable fields in document order.

  • Text and password inputs are filled character by character and emit input and change events.
  • Textareas are supported and existing values are replaced.
  • Selects match normalized option values first, then visible labels, using exact, prefix, and unambiguous partial matches.
  • Processing stops when either the copied values or eligible destination fields run out.
Not supported: other input types, contenteditable regions, fields inside iframes or shadow roots, hidden or disabled fields, and browser-internal pages.

Make it yours

Settings reference.

Open the toolbar popup, then choose Settings. Changes are saved automatically.

Extension on/off

The popup pauses or resumes Tabby Paste globally. It remains available even when the current URL is excluded.

Enabled URLs

Enter one HTTP or HTTPS wildcard pattern per line. Leave the list empty to allow every website.

https://*.example.com/*

Delay after each operation

Choose 0–5000 ms when a form needs extra time to validate, render, or move focus.

Wait for dynamic options

Keep this enabled when select options load after another field changes.

Import and export

TOML backup includes enabled URLs, delay, and dynamic-option waiting. The temporary global on/off state is not exported.

Browser-managed settings

Use the provided links to change the keyboard shortcut or open the browser's extension management page.

When it does not run

Troubleshooting common messages.

Clipboard could not be read

Copy the row again, keep the page active, and rerun Tabby Paste from a user action.

No text in the clipboard

Copy a single row before running the extension.

No input fields found

Confirm the page uses a supported visible field and that it is not inside an iframe or shadow root.

Focus an input field first

Click the exact first supported field, then run the command again.

The popup says this URL is disabled

Update the enabled URL patterns or test on a normal HTTP/HTTPS page.

A select was not changed

Check that the copied value matches an option value or label, and enable dynamic-option waiting if options load late.

Transparent permissions

What Tabby Paste accesses and why.

The extension does not collect data or communicate with a developer-controlled server. The destination website can still react to values entered into its form.

FAQ

Frequently asked questions.

Can I paste multiple spreadsheet rows at once?

No. Tabby Paste maps tab-separated values from one row to one sequence of fields. Process each row separately.

Can I change the shortcut?

Yes. Open Settings, use the keyboard-shortcut link, and assign a combination supported by your browser.

Which settings are synchronized?

The browser syncs enabled URLs, delay, dynamic-option waiting, and global enabled state when sync is available.

Does Tabby Paste send my form data anywhere?

No. The extension itself uses the clipboard and page locally and has no developer server or analytics.

Still need help?

Report a reproducible problem.

Include the browser, page type, copied value shape, destination field types, and any Tabby Paste message. Do not include sensitive clipboard data.
