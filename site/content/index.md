# Tabby Paste

One spreadsheet row, every field.

Tabby Paste is a browser extension for Chrome, Edge, and Firefox that copies tab-separated values from one clipboard row into successive web form fields, beginning with the field you focus.

## Main workflow

1. Copy one row from Excel, Google Sheets, or another tab-separated source.
2. Focus the first field that should receive a value.
3. Run Tabby Paste from the configured keyboard shortcut or the page context menu.

Each tab-separated value is applied to the next eligible field in document order.

## Built for real forms

- Text fields, textareas, password fields, and select elements are supported by the current product workflow.
- URL patterns can limit where the extension is enabled.
- Select-option matching can wait for dynamically rendered options.
- Settings can be exported and imported for reuse.
- Same-origin iframe and legacy frame documents are supported by the extension flow; cross-origin or sandboxed frames may require permissions that are not part of the current permission set.

## Supported browsers

- Google Chrome
- Microsoft Edge
- Mozilla Firefox

## Privacy

Clipboard values are processed for the requested paste operation. Tabby Paste does not use developer-controlled analytics, advertising, accounts, or a developer-controlled server for clipboard data.
